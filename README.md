# موقع عرض جامعي: تكنولوجيا الإعلام والاتصال

## الملفات
- `index.html`: محتوى الموقع وأقسام العرض.
- `style.css`: التصميم المتجاوب والأسلوب التقني الداكن.
- `script.js`: التفاعلات والتنقل ووضع العرض.

## التشغيل
1. فك ضغط الملف `ict_presentation.zip`.
2. افتح المجلد `ict_presentation`.
3. انقر مرتين على `index.html` لفتحه في متصفح حديث مثل Firefox أو Chrome أو Edge.

لا يحتاج الموقع إلى خادم أو تثبيت برامج، وتعمل التفاعلات محليًا. قد يحتاج الخط المخصص إلى اتصال بالإنترنت؛ إذا لم يتوفر، سيستخدم المتصفح خطًا بديلًا.

## وضع العرض
- اضغط زر **وضع العرض**.
- استخدم الأسهم ↑ و ↓ أو ← و → للتنقل بين الأقسام.
- اضغط Esc أو زر ✕ للخروج.
- يدعم الموقع ملء الشاشة إذا سمح المتصفح بذلك.

## تخصيص بيانات الطالب
يمكنك تعديل العنوان في `index.html` وإضافة اسمك واسم الأستاذ والجامعة في الصفحة الرئيسية أو التذييل.

## ملاحظة للمراجع
روابط المؤسسات تفتح مواقعها الرسمية عند توفر الإنترنت. راجع بيانات الطبعة والصفحات لأي مرجع أكاديمي قبل إدراجه في نسخة بحث مكتوبة.


## رمز QR في بداية الصفحة
- يظهر رمز QR في أعلى الصفحة أسفل شريط التنقل.
- ارفع ملف `qr-code.png` إلى المستودع نفسه بجانب `index.html` و`style.css` و`script.js` حتى تظهر الصورة على GitHub Pages.
